# ESP32-S3-Touch-AMOLED-1.8 PlatformIO 项目

本项目旨在为 Waveshare 的 ESP32-S3-Touch-AMOLED-1.8 模块提供一个基础代码框架，支持快速开发。

## 硬件需求
- ESP32-S3-Touch-AMOLED-1.8 模块
- USB 数据线

## 软件需求
- [PlatformIO](https://platformio.org/) IDE
- Arduino 框架支持

## 功能
该项目将实现以下模块功能：
1. 触摸屏输入处理
2. AMOLED 显示屏驱动
3. 常见传感器或外设接口支持

## 使用方法
1. 将项目克隆到本地。
2. 使用 PlatformIO 打开项目。
3. 根据需要修改代码并上传到 ESP32-S3 模块。

更多硬件信息请参考 [Waveshare 官方文档](https://www.waveshare.net/wiki/ESP32-S3-Touch-AMOLED-1.8)。
